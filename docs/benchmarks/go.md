## Method

- **Ground truth:** `go list -e -json ./...` from go version go1.24.7 linux/amd64, run offline (`GOTOOLCHAIN=local`, `GOPROXY=off`, `GOFLAGS=-mod=mod`, `GOWORK=off`) on a pinned clone. It reads go.mod and the source files and loads no project code; it is a benchmark aid, never part of Epoch (ADR-006).
- **Compared:** package-to-package imports inside the main module. _Production_ uses each package's `Imports`; _tests_ uses `TestImports` and `XTestImports` (an external test package's import of its own package is left out on both sides).
- **Epoch's side** is each import's resolution (before the graph folds files into packages), attributed to the package of the importing file's directory, so the two sides count the same thing.
- **Build constraints:** `go list` evaluates them for this host's GOOS and GOARCH; Epoch does not (ADR-013). An Epoch-only edge that comes only from files `go list` reports as excluded (`IgnoredGoFiles`) is classified as such.
- **Host:** linux x64 (6.18.44-fc-v114), 4 × Intel(R) Xeon(R) Processor @ 2.10GHz, 16 GiB RAM, Node 24.21.0.

Generated by `pnpm bench:accuracy-python` (packages/bench/src/accuracy-python.ts). Do not edit by hand.

## Method

- **Ground truth:** grimp 3.17 (`build_graph`, cache off), in a throwaway virtualenv from `packages/bench/python/requirements.txt`. grimp parses the package with Python's `ast` module and imports none of it; it is a benchmark aid, never part of Epoch (ADR-006).
- **Compared:** module-to-module imports inside the `flask` package (`src/flask`), `TYPE_CHECKING` imports included on both sides (grimp's default).
- **Epoch's side** is each import's resolution, before barrel tracing, so a `from . import x` that names a function in `__init__.py` counts as an import of the package on both sides.
- **Every disagreement** is listed below with its reason. _Raw_ scores treat grimp as the truth; _adjusted_ scores use the agreed edges plus the real imports grimp misses (each listed with the rule that shows it is real). Unclassified disagreements count against Epoch.
- **Host:** linux x64 (6.18.44-fc-v114), 4 × Intel(R) Xeon(R) Processor @ 2.10GHz, 16 GiB RAM, Node 24.21.0.
